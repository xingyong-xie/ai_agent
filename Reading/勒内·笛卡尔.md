### 1.1 早年与游历（1596–1628）

笛卡尔出生于法国拉埃（今以他命名"笛卡尔镇"）的贵族家庭，一岁丧母，由外祖母抚养。8岁入拉弗莱舍耶稣会学院——当时欧洲最好的学校之一——接受了经院哲学和数学的严格训练。因体弱被特许每天上午躺在床上思考，这个习惯保持终生。

1618–1619年参军（荷兰军队和巴伐利亚军队），但从未真正作战。1619年11月10日，在巴伐利亚乌尔姆附近的一个"暖房"（有暖炉的房间）里，笛卡尔经历了著名的**"一夜三个梦"**——梦中他看到一本字典、一首诗集和"是与否"（Quod vitae sectabor iter?——我该走哪条人生道路？）。他醒来后认为这是天启，决心建立一种统一的、以数学为模板的"普遍科学"。

### 1.2 荷兰时期（1628–1649）

1628年后，笛卡尔移居荷兰，在那里度过了大部分创作生涯。他选择荷兰是因为这里有相对的宗教宽容和学术自由，更重要的是——**没人认识他**。他在荷兰换了二十多个地址，连最亲近的朋友都不知道他住在哪里。他的座右铭是"Bene qui latuit, bene vixit"（藏得好的人活得好）。

在荷兰的二十年间，他完成了《谈谈方法》（1637）、《第一哲学沉思集》（1641）、《哲学原理》（1644）等。但1633年伽利略被教会审判后，笛卡尔撤回了一部已经完成的宇宙论著作《论世界》——"我宁愿不发表，也不愿与教会冲突。"

### 1.3 瑞典与死亡（1649–1650）

1649年，瑞典女王克里斯蒂娜邀请笛卡尔到斯德哥尔摩做她的哲学教师。女王要求清晨5点上课，而笛卡尔一生习惯睡到中午。北欧的冬天加上凌晨起床，1650年2月他染上肺炎，11天后去世，享年53岁。他的遗骨后迁回法国，但头骨在辗转中丢失，至今下落不明。

## 三、核心思想

### 3.1 普遍怀疑与"我思故我在"

笛卡尔的起点：**怀疑一切可以怀疑的**。感官会欺骗我；我可能在做梦；可能有一个"邪恶的魔鬼"在欺骗我。但即使我在怀疑一切，那个正在怀疑的"我"必定存在。这是一个不可怀疑的支点——阿基米德点。

### 3.2 心物二元论

| | 思维实体（res cogitans） | 广延实体（res extensa） |
|------|---------|---------|
| **本质** | 心灵 | 物质 |
| **属性** | 不占空间，不可分，自由 | 占空间，可分，服从机械规律 |

人是两者的结合——不占空间的心灵如何推动占据空间的物质？这是哲学史上最著名的难题。笛卡尔说是通过松果腺，但没人信服。

### 3.3 天赋观念

洛克的白板说正是针对笛卡尔而来。笛卡尔认为某些观念是**天赋的**——不来自经验，而是心灵自带的：上帝的观念、几何公理、逻辑规律、自我的观念。

### 3.4 真理的标准

凡是我**清楚、明白**地知觉到的东西，就是真的。但"笛卡尔循环"——他用清楚明白来证明上帝存在，又用上帝存在来保证清楚明白是可靠的——至今是哲学史的经典争议。

## 四、思想对话

| 人物 | 关系 |
|------|------|
| **培根** | 同为近代哲学开端；培根走经验主义，笛卡尔走理性主义 |
| **伽利略** | 1633年伽利略被审判，笛卡尔撤回《论世界》 |
| **霍布斯** | 《沉思集》的反驳者之一；唯物主义 vs 二元论 |
| **斯宾诺莎** | 继承理性主义，把二元论推到一元论 |
| **莱布尼茨** | 继承理性主义；批判笛卡尔的"清楚明白"不够精确 |
| **[[约翰·洛克]]** | 经验主义的反击——天赋观念不存在，心灵是一块白板 |

## 五、阅读建议

1. 《谈谈方法》—— 最短、最易读，自传体，约60页
2. 《第一哲学沉思集》—— 哲学主著，六个沉思 + 反驳与答辩
3. 《哲学原理》—— 完整体系阐述
