## 三、核心思想

### 3.1 可证伪性原则

波普尔解决休谟"归纳问题"的方案：科学理论不能被"证实"，只能被"证伪"。一个命题是科学的，当且仅当它存在被观察推翻的可能性。弗洛伊德的精神分析、马克思主义的历史理论之所以不是科学，不是因为它们"错"了，而是因为它们**无法被证伪**——任何观察都可以被解释为支持它们的证据。

### 3.2 开放社会

波普尔将"封闭社会"（部落式的、教条的、集体主义的）与"开放社会"（批判的、个人的、民主的）对立。开放社会的核心不是"多数统治"，而是**可以不流血地更换统治者**的制度安排。他批评柏拉图的《理想国》是极权主义的思想源头。

### 3.3 渐进社会工程

反对乌托邦式整体社会改造（"蓝图式"），主张一步一步地解决问题、修正错误。这与他的科学哲学一脉相承：社会政策也应该是可证伪的——错了就改，而不是为了维护"伟大蓝图"而拒绝承认失败。

## 四、思想对话

| 人物 | 关系 |
|------|------|
| **休谟** | 波普尔承认休谟的"归纳问题"是他整个哲学的起点，但拒绝休谟的"习惯"解释 |
| **维特根斯坦** | 1946年剑桥"拨火棍事件"——两人在道德科学俱乐部激烈争论哲学方法 |
| **维也纳学派** | 波普尔反对逻辑实证主义的"可证实原则"，被称为"官方反对派" |
| **哈耶克** | 挚友；两人在开放社会、自发秩序等议题上相互影响 |
| **爱因斯坦** | 波普尔心目中的科学典范——广义相对论敢于做出可被检验、可被推翻的预测 |

## 五、阅读建议

### 入门路径

1. 《历史决定论的贫困》—— 篇幅最短，论点集中
2. 《开放社会及其敌人》—— 波普尔最知名的社会政治著作
3. 《猜想与反驳》—— 科学哲学的最佳入门
4. 《无尽的探索》—— 思想自传，了解波普尔如何形成自己的观点

### 注意事项

- 波普尔在中文世界被标签化为"反马克思主义者"，但他的批判对象远不止马克思——柏拉图、黑格尔同样是靶子
- 他的科学哲学和社会政治哲学是**同一套批判理性主义**在两个领域的应用，不能割裂理解
