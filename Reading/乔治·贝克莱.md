# 乔治·贝克莱·著作概览

> **"存在即被感知。"**（Esse est percipi.）
>
> —— 《人类知识原理》

## 一、生平

| 项目 | 内容 |
|------|------|
| **姓名** | 乔治·贝克莱（George Berkeley） |
| **生卒** | 1685年3月12日 – 1753年1月14日（享年67岁） |
| **国籍** | 爱尔兰（英格兰裔） |
| **身份** | 哲学家、克洛因主教（爱尔兰圣公会） |
| **学派** | 英国经验主义；唯心主义 |
| **核心贡献** | 非物质论——物质不存在，只存在心灵和观念 |

### 1.1 天才少年（1685–1713）

贝克莱出生于爱尔兰基尔肯尼郡一个英格兰裔乡绅家庭。他的父亲是威廉堡的税务官。11岁入基尔肯尼公学（斯威夫特曾在此就读），15岁入都柏林三一学院——爱尔兰最好的大学。

在三一学院，他读了笛卡尔、洛克、牛顿和马勒伯朗士。1707年（22岁）当选三一学院院士，开始讲授希腊语、希伯来语和神学。此时他形成了核心直觉：洛克的"物质实体"是一个**不必要的假设**——既然我们只感知到观念，为什么要假设观念背后有一个永远感知不到的"东西"？

接下来的爆发令人震惊：

- 1709年（24岁）：《视觉新论》
- 1710年（25岁）：《人类知识原理·第一部》——所有重要论证都在这里
- 1713年（28岁）：《海拉斯与斐洛诺斯对话三篇》——通俗版

**三部著作全在30岁前完成。** 他计划写《人类知识原理》第二部（关于道德和上帝），但在意大利旅行时手稿丢失，从此放弃了系统哲学写作。

### 1.2 百慕大梦想（1713–1734）

贝克莱不仅是一个哲学家——他自认是一个**有使命的教士**。他观察到18世纪英国社会的道德沦丧（南海泡沫、赌博、酗酒），认为根源在于物质主义的哲学——如果人们相信只有物质是真实的，道德就会瓦解。

于是他产生了一个宏大的计划：**在百慕大建立圣保罗学院**，教育美洲殖民者和原住民，"从西方帝国输入宗教和学问"。他游说英国议会多年，获得了2万英镑的拨款许诺（这笔钱来自没收的詹姆斯党人地产）。1728年，他与新婚妻子安妮·福斯特（三一学院前议长的女儿）远赴新大陆。

他们在罗德岛的纽波特等待拨款到位，贝克莱在那里买了一处农场（"白厅"），建了图书馆，与当地知识分子（包括乔纳森·爱德华兹——后来的"大觉醒"领袖）交流。他写了《阿尔西弗龙》，并留下了日后成为加州大学伯克利分校得名来源的诗句："帝国的西进之路取道西方。"

等了三年，拨款从未到来——英国议会只是口头承诺。1731年，他带着失望回到英国。

### 1.3 克洛因主教与焦油水（1734–1753）

1734年，贝克莱被任命为爱尔兰克洛因主教，在那里度过了最后19年。这是一个小教区，远离学术中心，但贝克莱以罕见的热忱管理——他推动当地纺织业、建立学校、在饥荒中亲自施粥。

晚年他沉迷于一个出人意料的发现：**焦油水（pine tar 溶于水）的医疗功效**。他声称焦油水能治疗天花、痢疾、痛风、坏血病等一切疾病。1744年出版的《西里斯》前半部分是关于焦油水的化学和医学分析，后半部分却逐渐上升到关于宇宙神圣秩序的哲学沉思——从松树的焦油一路推导到柏拉图和普罗提诺的"太一"。

**这本"偏方"著作在他生前销量超过了所有哲学著作总和**——《海拉斯对话》第一版只卖了不到200本，《西里斯》在六个月内重印六次。

1752年，贝克莱移居牛津（名义上是为了监督儿子的教育）。1753年1月14日，他在牛津去世。据家人说，他是在听妻子给他读《哥林多前书》第15章（关于复活）时，安详地离世。

|------|------|---------|
| 1709 | *An Essay Towards a New Theory of Vision* 《视觉新论》 | 视觉距离不是直接感知的，而是通过触觉经验学会的 |

| 1744 | *Siris* 《西里斯》 | 从焦油水的药效出发，展开关于宇宙神圣秩序的哲学沉思 |

## 三、核心思想

### 3.1 物质不存在

贝克莱的逻辑极其简洁：

1. 我们感知到的只有**观念**（颜色、声音、形状等）
2. 观念只能存在于**心灵**中
3. 所谓的"物质实体"——观念背后的那个"东西"——我们从未感知过它
4. 一个从未被感知、也无法被感知的"东西"，说它"存在"是什么意思？

结论：**物质不存在**。洛克说雪球在黑夜中不是白色的——贝克莱说黑夜中根本没有雪球。没有感知，就没有存在。

休谟评价贝克莱："他的论证不容任何回答，也不产生任何确信。"

### 3.2 上帝作为永恒的感知者

如果"存在即被感知"，那没有人看的时候桌子还在吗？贝克莱的回答：**上帝在感知它**。上帝是永恒的、无限的感知者，一切观念在上帝心灵中永恒存在。所以世界不会因为你闭上眼睛就消失——不是因为你还在，而是因为上帝在。

约翰逊博士曾踢一块石头说："我这样反驳他（I refute him thus）"——但他误解了贝克莱。贝克莱并不否认你会感到脚疼（那是真实的观念），他否认的是那块"石头"作为**物质实体**的存在。

### 3.3 经验主义的极端推论

贝克莱的出发点和洛克、休谟完全一样——一切知识来自经验。但他把经验主义推到了洛克自己都不敢去的地方：如果只有经验到的才存在，那"物质"这种永远经验不到的东西就必须被剃掉。这是**奥卡姆剃刀**的最激进应用。

## 四、思想坐标

| 人物 | 关系 |
|------|------|
| **[[约翰·洛克]]** | 继承经验主义；洛克区分第一性质/第二性质→贝克莱说第一性质也是观念 |
