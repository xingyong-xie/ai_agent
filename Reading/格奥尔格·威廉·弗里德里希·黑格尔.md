> **"凡是合理的都是现实的，凡是现实的都是合理的。"**

| 项目 | 内容 |
|------|------|
| **姓名** | 格奥尔格·威廉·弗里德里希·黑格尔 |
| **生卒** | 1770年8月27日 – 1831年11月14日（享年61岁，死于霍乱） |
| **国籍** | 普鲁士 |
| **身份** | 哲学家、柏林大学教授 |
| **学派** | 德国唯心主义（集大成者） |
| **核心贡献** | 辩证法、绝对精神、主奴辩证法、历史哲学 |

图宾根神学院与荷尔德林、谢林同窗。1806年耶拿战役炮火中完成《精神现象学》，看到拿破仑骑马穿过城市："我看见皇帝——这个世界精神——骑马出城侦察。"1818年任柏林大学教授，统治德国哲学界十三年。1831年霍乱去世，葬在费希特旁边。

|------|------|---------|

## 三、核心思想

### 3.1 辩证法

**正题 → 反题 → 合题**。不是"辩论技巧"，而是实在本身的结构。每个立场包含内在矛盾，矛盾推动向更高阶段的**扬弃**（Aufhebung）——既否定又保留、既取消又提升。

### 3.2 主奴辩证法

两个自我意识相遇，要求对方承认。生死斗争中，怕死的成为奴隶，不怕死的成为主人。但反转：主人依赖奴隶，奴隶通过**劳动改造世界**获得独立意识。马克思从这里拿走"劳动创造人"和"阶级斗争"。

### 3.3 绝对精神与历史哲学

全部实在是绝对精神自我认识的过程。历史是自由的实现：东方只有一人自由→希腊罗马部分人自由→日耳曼世界所有人自由。"理性的狡计"：伟人以为在追求野心，实际上在执行世界精神的任务。
