# 约翰·洛克·著作概览

> **"人人生而自由、平等、独立，未经本人同意，不得将任何人置于这种状态之外，使其受制于他人的政治权力。"**
>
> —— 《政府论·下篇》

### 1.1 早年与牛津（1632–1667）

洛克出生于萨默塞特郡一个清教徒律师家庭。父亲是议会军的骑兵军官。1647年入威斯敏斯特公学，1652年入牛津基督教堂学院。他在牛津接受了经院哲学的训练，但厌恶亚里士多德式的枯燥逻辑——笛卡尔的新哲学和波义耳的实验科学更吸引他。他获得了医学学位，但从未正式执业。

### 1.2 沙夫茨伯里与流亡（1667–1689）

1667年，洛克成为沙夫茨伯里伯爵一世（Anthony Ashley Cooper）的私人医生和顾问。沙夫茨伯里是辉格党的创始人、查理二世的反对派领袖。这段关系改变了洛克的一生——他不仅是医生，还是伯爵的政治智囊、秘书、家庭教师。

1683年，沙夫茨伯里因参与反对查理二世的密谋而失势，死于流亡。洛克也因涉嫌参与"黑麦屋阴谋"（刺杀国王和约克公爵的计划）而逃往荷兰。在荷兰的五年（1683–1688）是他创作力最旺盛的时期，完成了《人类理解论》和《政府论》的大部分。

### 1.3 光荣革命与晚年（1689–1704）

1688年光荣革命后，洛克随玛丽公主返回英国。此后五年，他连续出版了毕生最重要的著作：《论宽容》（1689）、《人类理解论》（1689）、《政府论两篇》（1690）、《教育漫话》（1693）。一年之内，他成为欧洲最著名的哲学家。

晚年隐居埃塞克斯的奥茨庄园，住在马沙姆夫妇（达马里斯·马沙姆是他的哲学对话者）家中。1704年去世，葬于海拉弗教堂。

## 三、核心思想

### 3.1 白板说

> 心灵最初是一张白纸（tabula rasa），没有任何先天观念。一切知识来自经验。

洛克反对笛卡尔的"天赋观念"——不存在人生而就知的真理。所有观念要么来自**感觉**（外部经验），要么来自**反省**（内部经验——心灵对自己活动的觉察）。简单观念是建筑材料，复杂观念是心灵对简单观念的组合、比较和抽象。

### 3.2 第一性质 vs 第二性质

| | 第一性质 | 第二性质 |
|------|---------|---------|
| **定义** | 物体本身具有的 | 物体的能力在我们感官中产生的 |
| **例子** | 大小、形状、运动、数目 | 颜色、声音、味道、气味 |
| **客观性** | 客观存在 | 依赖于感知者 |

雪球在黑夜中还是白色的吗？——白不是雪球本身的性质，而是它在我们心灵中产生白色感觉的能力。没有眼睛，就没有颜色。

### 3.3 自然权利与社会契约

洛克论证：在自然状态中，人是自由、平等的，但财产不安全。人们通过**社会契约**建立政府——政府存在的唯一正当目的是保护自然权利（生命、自由、财产）。主权在民。如果政府违背了被统治者的信任，人民有权**反抗和推翻**它。

### 3.4 政教分离

教会只关心灵魂，政府只关心世俗事务。强制信仰毫无意义——信仰不能靠暴力产生。但洛克不宽容天主教徒（效忠外国君主）和无神论者（誓言不可信）——他的宽容有边界。

## 四、思想对话

| 人物 | 关系 |
|------|------|
| **笛卡尔** | 洛克的反面——批判"天赋观念" |
| **霍布斯** | 同为契约论者；霍布斯的自然状态是"一切人对一切人的战争"，洛克的相对和平 |
| **牛顿** | 洛克以牛顿物理学为楷模——他的哲学是牛顿科学方法的哲学辩护 |
| **卢梭** | 继承契约论，走向完全不同的方向（公意） |
| **贝克莱** | 将洛克的经验主义推到极端——物质不存在 |
| **[[大卫·休谟]]** | 将洛克的经验主义推到逻辑终点——因果关系也只是习惯 |
| **美国建国者** | 杰斐逊、麦迪逊几乎逐字复制洛克的语言写进《独立宣言》 |

## 五、阅读建议

1. 《政府论·下篇》—— 现代自由主义的基石，约150页
2. 《论宽容》—— 短小精悍，约50页
3. 《人类理解论》—— 哲学主著，洛克比大多数哲学家都清晰易懂
