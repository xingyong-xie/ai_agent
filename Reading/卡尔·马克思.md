# 卡尔·马克思·著作概览

> **"哲学家们只是用不同的方式解释世界，而问题在于改变世界。"**
>
> —— 《关于费尔巴哈的提纲》

---

## 一、生平

| 项目 | 内容 |
|------|------|
| **姓名** | 卡尔·海因里希·马克思 |
| **生卒** | 1818年5月5日 – 1883年3月14日（享年64岁） |
| **国籍** | 普鲁士（特里尔出生），无国籍流亡者 |
| **身份** | 哲学家、经济学家、革命理论家 |
| **学派** | 黑格尔左派 → 历史唯物主义 |
| **核心贡献** | 历史唯物主义、剩余价值理论、异化理论、意识形态批判 |

特里尔犹太律师家庭。柏林大学期间成为青年黑格尔派。1844年遇恩格斯，确立终身合作。1848年《共产党宣言》发表。流亡伦敦三十余年，在大英博物馆阅览室写出《资本论》。三个孩子夭折，靠恩格斯资助维生。1883年去世。

## 三、核心思想

### 3.1 历史唯物主义

> "不是人们的意识决定他们的存在，而是社会存在决定他们的意识。"

把黑格尔"倒过来"：生产力→生产关系→上层建筑（法律、政治、宗教、哲学）。经济基础决定上层建筑。

### 3.2 异化

四重异化：与劳动产品的异化、与劳动过程的异化、与类本质的异化、与他人的异化。

### 3.3 剩余价值

工人劳动创造的价值大于维持生存的工资——差额就是剩余价值。利润不是来自"聪明的投资"，而是来自**剥削**。

### 3.4 阶级与革命

一切历史都是阶级斗争史。资本主义内在矛盾：生产力越来越社会化，生产资料越来越集中。无产阶级的解放意味着所有人的解放。
