# 康德之后的哲学发展

> **康德之后，再也没有一个哲学家能绕开他。** 你可以反对他，但不能忽略他。从德国唯心主义到20世纪分析哲学与欧陆哲学的分流，一切都可以追溯到康德留下的那个问题：现象与物自体之间的裂缝。

## 二、德国唯心主义：康德的直接继承人

### 核心问题

康德留下了什么？现象与物自体的区分。但这个问题激怒了所有后来者：**如果物自体永远不可知，那你怎么知道它存在？**

德国唯心主义的回答：**取消物自体。** 把一切都还原为精神/理性的自我展开。

### 2.1 费希特（Johann Gottlieb Fichte, 1762–1814）

| 关键著作 | 说明 |
|---------|------|
| 1794 《全部知识学的基础》 | 从"自我"出发推演一切 |

**核心推进**：取消康德的物自体——所有东西都是**"自我"（das Ich）设定的**。"非我"（世界、自然）只是自我为了展开自身而设定的对立面。自我设定自我→自我设定非我→自我在非我中认识自身。

**一句话**：不是"我在世界之中"，而是**世界在我之中**。

### 2.2 谢林（Friedrich Wilhelm Joseph Schelling, 1775–1854）

| 关键著作 | 说明 |
|---------|------|
| 1800 《先验唯心论体系》 | 自然哲学与先验哲学的统一 |

**核心推进**：费希特的"自我"太主观了。谢林说：自然和精神是同一个**绝对者**（das Absolute）的两面——自然是"可见的精神"，精神是"不可见的自然"。艺术是绝对者自我认识的最高的形式（这一点影响了后来的浪漫主义）。

**一句话**：主观和客观在**绝对者**中同一。

### 2.3 黑格尔（Georg Wilhelm Friedrich Hegel, 1770–1831）

| 关键著作 | 说明 |
|---------|------|
| 1807 《精神现象学》 | 意识从感性确定性到绝对知识的辩证旅程 |
| 1812–16 《逻辑学》 | 概念自身辩证运动的体系 |
| 1821 《法哲学原理》 | "凡是合理的都是现实的，凡是现实的都是合理的" |

**核心推进**：德国唯心主义的完成和终结。

- **辩证法**：正题→反题→合题。每个立场都包含内在矛盾，矛盾推动向更高阶段的运动。这不是"辩论技巧"，而是**实在本身的结构**。
- **绝对精神**：整个历史是绝对精神（上帝/理性/世界本身）通过自我异化和自我认识来实现自身的过程。拿破仑是"马背上的世界精神"。
- **历史哲学**：历史不是随机事件——它是**自由的实现过程**。东方只知道一个人是自由的（专制君主）；希腊罗马知道一些人是自由的（公民）；日耳曼世界知道所有人都是自由的。

**一句话**：全部实在都是**绝对精神**自我认识的过程。康德说理性不能认识物自体——黑格尔说**理性就是物自体**。

## 三、19世纪的反叛：四条路线

黑格尔死后（1831），他的体系被来自四面八方的力量撕裂。

### 3.1 黑格尔左派 → 马克思

| 人物 | 核心推进 |
|------|---------|
| **费尔巴哈** (1804–1872) | 不是上帝按照自己的形象造人，而是人按照自己的形象造上帝。**神学就是人类学** |
| **马克思** (1818–1883) | 把黑格尔"倒过来"——不是精神决定物质，而是**物质生活决定意识**。哲学不在于解释世界，而在于改变世界 |

**马克思的核心论证**：
- **历史唯物主义**：生产力（技术+劳动）决定生产关系（阶级结构），生产关系决定上层建筑（法律、政治、宗教、哲学）
- **异化**：工人在劳动中不是"实现自己"而是"丧失自己"——产品不属于他，劳动过程不属于他，甚至他的"类本质"（创造性）也不属于他
- **意识形态**：统治阶级的思想是每个时代占统治地位的思想——不是因为它"真"，而是因为它为统治阶级服务

**与黑格尔的关系**：马克思保留了黑格尔的辩证法（历史通过矛盾前进），但把"绝对精神"换成了**阶级斗争**。

### 3.2 叔本华：意志的反叛

| 关键著作 | 说明 |
|---------|------|
| 1819 《作为意志和表象的世界》 | **反黑格尔**。世界有两面：作为表象（现象）和作为意志（物自体） |

**核心推进**：

- 康德的"物自体"不是不可知的——它就是**意志**（Wille），一种盲目的、无目的的、永不停息的驱动力
- 生命就是**痛苦**：意志永不满足→欲望→满足后的空虚→新的欲望→永无止境
- **解脱之道**：艺术（短暂解脱——沉浸于审美时暂时忘却自我）、禁欲（否定意志本身）
- 黑格尔是有史以来最大的骗子——他把世界的残酷美化成"理性的展开"

**影响**：直接影响了瓦格纳、托尔斯泰、托马斯·曼；为尼采铺平了道路（尽管尼采后来反叛了他）。

### 3.3 克尔凯郭尔：个体的反叛

| 关键著作 | 说明 |
|---------|------|
| 1843 《恐惧与战栗》 | 亚伯拉罕献祭以撒——"信仰的骑士"超越伦理 |
| 1844 《哲学片段》 | 真理不是客观体系，而是主观的"投入" |
| 1849 《致死的疾病》 | 绝望是"自我的疾病" |

**核心推进**：

- **反黑格尔体系**：黑格尔的体系囊括了一切——除了那个正在写体系的具体存在的**个人**。真理不是体系，而是**主观性**（Subjectivity is Truth）。
- **人生三阶段**：审美（追求快乐→绝望）→伦理（承担责任→罪）→宗教（信仰的跳跃——亚伯拉罕献祭以撒：在伦理上是谋杀，在信仰上是服从）
- **恐惧与焦虑**：不同于害怕（害怕有具体对象），焦虑没有对象——它是面对"自由的可能性"时的眩晕
- **存在先于本质**：不是先有"人的本质"然后你活出来，而是**你怎样活，你就成为怎样的人**

**影响**：被遗忘近一个世纪，直到20世纪被海德格尔和萨特重新发现——**存在主义之父**。

### 3.4 尼采：一切价值的重估

| 关键著作 | 说明 |
|---------|------|
| 1872 《悲剧的诞生》 | 日神（阿波罗）vs 酒神（狄奥尼索斯） |
| 1882 《快乐的科学》 | "上帝死了" |
| 1883–85 《查拉图斯特拉如是说》 | 超人、权力意志、永恒轮回 |
| 1887 《论道德的谱系》 | 善恶的起源：主人的道德 vs 奴隶的道德 |

**核心推进**：

- **上帝死了**：不是无神论的论证——是一个**历史诊断**。基督教上帝不再能为西方文明提供意义基础。我们亲手杀死了他。接下来要么是虚无主义，要么是……
- **权力意志**：一切生命的本质不是"自我保存"（达尔文），而是**追求更强、更大、更多的权力**——这里的"权力"不是政治权力，而是**生命力、创造力、自我超越**
- **奴隶道德的起义**：基督教是"奴隶的道德"——弱者把"无力报复"重新解释为"宽恕"这种美德。耶稣是"最崇高的犹太人"，因为他完成了犹太人的终极复仇：把主人的价值（高贵、力量、骄傲）倒转为罪恶
- **永恒轮回**：如果你被告知你的一生将永远重复，你能承受吗？这是对生命的终极肯定——**不是"我忍受它"，而是"我要它再来一次！"**
- **超人**：不是更强的"人"，而是**超越人**——创造自己的价值，不依赖外部的"上帝"或"理性"

**一句话**：如果你不接受虚无主义，你必须创造你自己的价值。没有上帝，没有理性，没有历史规律可以替你做这件事。

## 四、20世纪：两大传统的分流

到了20世纪初，哲学分裂为两个几乎不对话的传统。

### 4.1 分析哲学（英美）

**起源**：弗雷格（数理逻辑）→ 罗素 → 早期维特根斯坦 → 维也纳学派

| 阶段 | 代表人物 | 核心主张 |
|------|---------|---------|
| **逻辑原子主义** | 罗素、早期维特根斯坦 | 语言可以分析为最基本的逻辑原子；命题是现实的图像 |
| **逻辑实证主义** | 石里克、卡尔纳普 | **可证实原则**：一个命题的意义就是它的证实方法。形而上学是无意义的——不是"假的"，而是"不可说的" |
| **日常语言哲学** | 后期维特根斯坦 | "意义即用法"——不要问"什么是真"，要看这个词在具体情境中怎么用。哲学问题是"语言放假"造成的 |
| **波普尔** | [[卡尔·波普尔]] | 反逻辑实证主义；科学不能被证实，只能被证伪 |
| **奎因** | "经验主义的两个教条" | 分析/综合的区分是教条；知识是一个整体网络，面对经验的是整个网络而非单个命题 |

**一句话概括**：分析哲学的核心信念——**哲学问题可以通过分析语言来解决**。形而上学的问题不是被回答了，而是被"消解"了。

### 4.2 欧陆哲学（法德）

**起源**：胡塞尔 → 海德格尔 → 萨特/梅洛-庞蒂 → 结构主义 → 后结构主义

#### 现象学

| 人物 | 核心主张 |
|------|---------|
| **胡塞尔** (1859–1938) | **"回到事物本身"**。搁置自然态度（是否存在外部世界），描述意识中直接给予的东西。意识总是**关于某物的意识**（意向性） |
| **海德格尔** (1889–1976) | 胡塞尔问"意识"，海德格尔问**"存在"**。人是**此在**（Dasein）——唯一追问存在的意义的存在者。人的基本状态不是"思维"，而是**"在世界中存在"**（Being-in-the-world） |
| **萨特** (1905–1980) | **"存在先于本质"**——你首先存在，然后通过行动定义自己。人被判定为自由——你不能不自由，选择"不选择"也是一种选择。**"他人即地狱"**：在他人的注视下，你被变成客体 |

#### 法兰克福学派（批判理论）

| 人物 | 核心主张 |
|------|---------|
| 霍克海默、阿多诺 | 《启蒙辩证法》：启蒙变成了新的神话——工具理性奴役人 |
| 马尔库塞 | 《单向度的人》：资本主义社会消除了否定的维度 |
| 哈贝马斯 | 交往理性——理性不是在孤独的自我中，而是在**对话**中 |

#### 结构主义 → 后结构主义

| 人物 | 核心主张 |
|------|---------|
| **索绪尔**（语言学） | 语言不是标签的集合——意义来自**差异**。狗叫"狗"不是因为它像狗，而是因为它不是"猫"、"狼"、"fox" |
| **福柯** (1926–1984) | **知识即权力**。疯癫、犯罪、性——这些不是"自然事实"，而是被**话语**建构出来的。每个时代有一套"真理制度"，它决定什么可以说、什么不可以说 |
| **德里达** (1930–2004) | **解构**。西方哲学是"在场的形而上学"——总是想找一个最终的"基础"（上帝、理性、自我）。解构就是揭示这个基础如何自己瓦解自己 |

**一句话概括**：欧陆哲学的核心信念——**理性、真理、自我不是给定的，而是被建构的**（被语言、权力、历史）。

### 4.3 两条路线的对比

| | 分析哲学 | 欧陆哲学 |
|------|---------|---------|
| **核心工具** | 逻辑、语言分析 | 历史、文本解释、社会分析 |
| **对形而上学的态度** | 消解（没有意义的问题） | 解构（问题被历史地建构） |
| **对科学的态度** | 典范（哲学应该像科学一样清晰） | 批判（科学也是一种话语权力） |
| **风格** | 论文、论证 | 著作、阐释 |
| **地理** | 英美 | 法德 |
| **与康德的关系** | 继承康德对形而上学的批判 | 继承康德对理性边界的追问 |
