# 弗里德里希·尼采·著作概览

> **"上帝死了。上帝还是死的。是我们杀死了他。"**
>
> —— 《快乐的科学》

---

## 一、生平

| 项目 | 内容 |
|------|------|
| **姓名** | 弗里德里希·威廉·尼采 |
| **生卒** | 1844年10月15日 – 1900年8月25日（享年55岁） |
| **国籍** | 普鲁士，后入瑞士籍 |
| **身份** | 哲学家、古典语言学家 |
| **学派** | 无法归类——"用锤子做哲学" |
| **核心贡献** | 上帝已死、权力意志、超人、永恒轮回、道德的谱系 |

牧师家庭，5岁丧父。24岁成为巴塞尔大学最年轻的古典语言学教授。35岁因病辞职，此后十年独自漫游于瑞士、意大利、法国南部，在流浪和病痛中写下了最辉煌的著作。1889年都灵抱马崩溃，此后十年精神错乱，由母亲和妹妹照料。妹妹伊丽莎白（纳粹同情者）篡改手稿编造《权力意志》，将其包装成"纳粹哲学家"。

## 三、核心思想

### 3.1 上帝死了

不是无神论论证——是历史诊断。基督教上帝不再能为西方文明提供意义基础。接下来要么是虚无主义，要么是重估一切价值。

### 3.2 权力意志

一切生命的本质不是"自我保存"，而是追求更强、更广、更大的权力——生命力、创造力、自我超越。

### 3.3 主人道德 vs 奴隶道德

基督教是"奴隶的道德"——弱者把"无力报复"重新解释为"宽恕"这种美德。善恶不是天然的，是**被创造出来的**。

### 3.4 超人与永恒轮回

超人创造自己的价值，不依赖外部的"上帝"或"理性"。永恒轮回是伦理检验：你的生活能否承受"再来一次"？
