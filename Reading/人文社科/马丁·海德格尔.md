# 马丁·海德格尔·著作概览

> **"为什么是存在者存在，而不是无？"**
>
> —— 《形而上学是什么？》

---

## 一、生平

| 项目 | 内容 |
|------|------|
| **姓名** | 马丁·海德格尔 |
| **生卒** | 1889年9月26日 – 1976年5月26日（享年86岁） |
| **国籍** | 德意志（梅斯基希出生） |
| **身份** | 哲学家、弗莱堡大学教授 |
| **学派** | 现象学 → 存在主义 |
| **核心贡献** | 存在的追问、此在（Dasein）、在世存在、向死而在 |

黑森林教堂司事之子，原计划成为神父。1927年《存在与时间》一夜成名。1933年加入纳粹党、出任弗莱堡大学校长——20世纪最重要的哲学家之一曾是一个纳粹，这是无法回避的阴影。1930年代"转向"后关注技术、语言、诗和栖居。黑森林托特瑙山小木屋中完成大部分写作。1976年去世。

## 三、核心思想

### 3.1 存在的追问

西方哲学史把"存在"当成了"存在者"——把"是什么"当成"存在本身"。我们忘记了存在是**动词**，不是名词。

### 3.2 此在（Dasein）

人是唯一追问存在意义的存在者。此在的本质不是"思维"，而是"去存在"——不是固定的"什么"，而是不断地"成为"。

### 3.3 在世存在

你不是先有一个"我"然后被放进"世界"。你从来就已经在世界之中——与世界的关系不是主体与客体，而是锤子与钉子。

### 3.4 向死而在与技术批判

只有意识到死亡是不可替代的，才能从"常人"（das Man）中挣脱出来本真地活。晚期：现代技术把一切变成"持存物"——河流不再是河流，而是"水力资源"。
