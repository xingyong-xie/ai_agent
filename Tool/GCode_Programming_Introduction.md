# G 代码编程入门

> G 代码（G-code）是数控机床（CNC）的标准编程语言，用于控制刀具路径、主轴转速、进给速度、冷却液等。

---

## 一、手工编程

适合简单零件（2.5 轴加工），直接在文本编辑器中编写。

```
G21          ; 公制单位 mm
G90          ; 绝对坐标
G17          ; XY 平面
M03 S12000   ; 主轴正转 12000 RPM
G00 Z10      ; 快速抬刀到安全高度
G00 X0 Y0    ; 快速移动到原点
G01 Z-2 F200 ; 直线下刀 2mm
G01 X100 F800; 直线切削到 X100
G01 Y50      ; 直线切削到 Y50
M05          ; 主轴停转
M30          ; 程序结束
```

### 常用指令分类

| 类别 | 指令 | 含义 |
|------|------|------|
| **运动** | G00 | 快速定位（空走） |
| | G01 | 直线插补（切削进给） |
| | G02/G03 | 顺/逆时针圆弧 |
| **坐标系** | G54-G59 | 选择工件坐标系 |
| **单位** | G20/G21 | 英寸 / 毫米 |
| **刀具** | T01 M06 | 换 1 号刀 |
| **主轴** | M03 Sxxx | 主轴正转 |
| | M05 | 主轴停转 |
| **冷却液** | M08 | 冷却液开 |
| | M09 | 冷却液关 |
| **程序控制** | M30 | 程序结束并回开头 |

## 二、CAM 软件自动生成（主流方式）

复杂零件基本不手写代码，通过 CAM（计算机辅助制造）软件从 3D 模型自动生成。

```
CAD 建模（SolidWorks / Fusion 360 / NX）
    → CAM 编程（定义刀具/策略/参数）
        → 后处理器（Post-Processor）→ 生成 G 代码
            → 传输到 CNC 控制器（Haas / Fanuc / Siemens / Heidenhain）
```

### 常用 CAM 软件

| 软件 | 定位 |
|------|------|
| **Fusion 360** | 入门首选，CAD/CAM 一体，免费试用 |
| **Mastercam** | 工业标准，2D~5 轴 |
| **SolidCAM** | SolidWorks 深度集成 |
| **NX CAM** | 高端五轴、航空叶片 |
| **PowerMill** | 模具、五轴精加工 |
| **FreeCAD Path** | 开源免费 |

## 三、编程流程（以 Fusion 360 为例）

1. **导入/建模** → 打开 CAD 模型
2. **定义毛坯** → 设定原材料尺寸
3. **创建刀具** → 选刀（端铣刀、球刀、钻头等），设定转速/进给
4. **定义加工策略：**
   - **粗加工**（Adaptive Clearing）→ 快速切除大部分材料
   - **精加工**（Contour / Parallel）→ 达到最终尺寸和表面光洁度
   - **钻孔**（Drilling）→ 孔加工
5. **生成刀具路径** → 模拟仿真，检查碰撞
6. **后处理** → 选择对应机床的后处理器，输出 `.nc` / `.tap` 文件
7. **传输** → U 盘 / RS232 / 网络传到机床控制器

---

## 四、关键参数

| 参数 | 含义 |
|------|------|
| **S（Spindle Speed）** | 主轴转速 RPM |
| **F（Feed Rate）** | 进给速度 mm/min |
| **切削深度** | 每层吃刀量 |
| **步距** | 相邻刀路间距 |
| **转速进给计算** | `F = S × 齿数 × 每齿进给` |

---

## 五、后处理器（Post-Processor）

CAM 生成的只是通用刀具路径，后处理器将其翻译为特定机床能识别的 G 代码方言。同样的路径，Fanuc 和 Heidenhain 的输出完全不同。

后处理器需要匹配：
- **机床品牌**（Fanuc / Siemens / Haas / Heidenhain）
- **轴数**（3 轴 / 4 轴 / 5 轴）
- **特殊功能**（探头测量、刀库管理、子程序调用）

---

## 六、学习路径

```
入门: 理解坐标系（G54）+ 基本运动指令 → 手写简单二维轮廓
  ↓
进阶: 学习 Fusion 360 CAM → 生成三轴代码 → 在模拟器中验证
  ↓
实战: 上机操作 → 理解装夹/对刀/刀具补偿(G41/G42/G43)
  ↓
高级: 五轴编程 / 宏程序(变量+循环) / 后处理定制
```
